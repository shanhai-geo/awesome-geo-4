# Contributing

Thanks for helping keep this the most honest GEO/AI-search reference on GitHub.

## The one hard rule

**Primary source, or it doesn't go in.**

| Type of source | Where it goes |
|---|---|
| Official engine docs (Google, OpenAI, Perplexity, Anthropic, Microsoft) | Main sections, stated as fact |
| Standards bodies (schema.org, W3C) | Main sections |
| Vendor blogs, agency posts, analyses | *Industry & Academic References* — clearly labeled, never stated as Google/engine policy |
| Reverse-engineered "ranking factor" claims with no official confirmation | **Rejected** |

## How to add a link

1. Add it to the relevant table with a one-line **why it matters** column.
2. Use the canonical/official URL (no tracking params, no AMP).
3. If it's a vendor/marketing source, put it in the secondary section.
4. Keep the tone neutral on facts, skeptical of hype.

## PR checklist

- [ ] Link is a primary source (or correctly placed in the secondary section)
- [ ] One-line rationale included
- [ ] No duplicate of an existing entry
- [ ] Alphabetical / logical order preserved within its table

Open a PR or an issue. Disagreements about whether something is "official" are welcome in issues.
